# 可视化智能体分析路径规划

算法设计课程演示项目。使用动态规划，在给定资源预算下为可视化智能体选择收益最大的分析路径，并依次执行能源数据分析操作。

## 运行方式

使用 Python 3.10 或以上版本，无需安装第三方依赖。

在 PyCharm 中打开项目，右键运行 `main.py`；也可以在项目目录执行：

```bash
python main.py
```

启动后自动打开 Chrome；未找到 Chrome 时使用默认浏览器。默认地址为 `http://127.0.0.1:8765`，端口被占用时会自动更换，以控制台显示为准。点击 PyCharm 停止按钮或按 `Ctrl+C` 结束服务。

## 演示内容

- 调整预算，查看智能体选择的分析路径。
- 逐步查看趋势分析、地区定位、能源细分及解释结果。
- 对比动态规划与局部贪心，查看状态值和决策依据。

标准案例预算为 6，动态规划收益为 14，局部贪心收益为 9。

## 主要文件

- `main.py`：启动入口与本地服务。
- `planner.py`：动态规划与对比算法。
- `scenarios.py`：分析状态、操作及评分。
- `agent.py`：工具执行与分析证据传递。
- `data_tools.py`：数据处理与分析工具。
- `static/`：演示页面。
- `data/`：能源样本数据。

数据为合成样本，成本与收益为教学设定；当前采用规则型工具智能体，未接入大语言模型。
